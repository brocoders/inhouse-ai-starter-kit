# Kit feedback

One dated line per thing in the kit that got in the way, and what was done
instead. Written as it happens — by the agent at the end of the `release`
skill, which asks, or by hand when something bites. The kit's owner reads this
file to decide what the next version changes.

A line is enough: the date, what the kit did or lacked, the workaround.
